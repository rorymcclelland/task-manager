# QA report — 14 October 2026

_Version tested: 0.5.0 (commit `1e01f25`, Phases 0–5) · All findings
fixed in 0.6.0 (Phase 6 — Hardening in [`BACKLOG.md`](../BACKLOG.md)) and
retested; see [Retest](#retest--v060) at the end._

## Summary

The app does what the backlog says and stays honest under bad input,
with one serious exception: **any website could change tasks** through
the running app (Q1). Four medium issues affect dates, unreadable files,
UTF-16 inbox files and light-mode contrast. The rest are low.

| | Result |
|---|---|

| Type check | Clean |
| Lint of browser code | Clean (one false positive, explained below) |
| Scripted browser walkthrough | 40 checks; every feature works (four failures were test-script mistakes, each rechecked by hand) |

### 1. Other websites can change tasks — High

**Seen:** a page served from a different address
(`http://127.0.0.1:4600`) ran this in Chromium:

```js
fetch('http://localhost:4500/api/capture', {
  method: 'POST', mode: 'no-cors',
  headers: { 'Content-Type': 'text/plain' },
  body: JSON.stringify({ text: 'Planted from another site !1' }),
});
```

The task appeared in Do now. The same works for `/complete` and `/drop`
on any task id. `text/plain` bodies are "simple" requests that browsers
send without asking, and the server parses any body as JSON whatever its
type. It doesn't check `Origin`.

Separately, a request with `Host: evil.example` is answered normally.
That makes a DNS-rebinding attack possible, where a site switches its
address to 127.0.0.1 and can then *read* the task list too.

**Not affected:** cross-origin pages can't read responses (no CORS
headers are sent), and the server only listens on 127.0.0.1, so other
devices on the network can't reach it. Newer browsers are adding
prompts for sites that talk to local addresses, but they can't be relied
on.

### 2. Impossible dates accepted — Medium

`POST /api/capture {"text":"Pay rent due:2026-02-31 on:2026-04-31"}`
stores both dates. `2026-13-45` comes back with `dueInDays: null` and
urgency reason "due-later", and is listed under Ahead's "due after that".
`2026-02-30` counts as overdue by 226 days. `GET /api/agenda?from=2026-02-30`
returns `to: 2026-03-02`. Cause: `isDateString` in `src/model.ts` checks
the pattern `YYYY-MM-DD`, not that the day exists.

### 3. Unreadable task file — Medium

With `tasks.json` truncated mid-write, every request returns 500 and the
page shows *"Couldn't reach the task server: Something went wrong — see
the server console"*, which points at the wrong problem. A valid file
with a UTF-8 byte-order mark in front (as older Notepad saves) fails the
same way. A file with `"version": 2` fails the same way too.

**Good:** in every case the file was left exactly as it was. No request
writes until the file has been read successfully. CRLF line endings are
fine.

### 4. UTF-16 inbox files — Medium

Windows PowerShell 5 writes UTF-16 LE for `"…" > file.md`. Such a file in
the inbox produced two tasks titled `"\u0000"` and
`"��-\u0000 \u0000U\u0000T…"`, and was moved to `processed`. UTF-8 with
a byte-order mark and CRLF line endings, as Notepad saves, imported
correctly.

### 5. Light-mode contrast — Medium

Measured with axe-core 4.10 against the light background (`#f6f5f2`):

| Text | Ratio | Needed |
|---|---|---|
| Delegate chip, idle label (`#b7791f`) | 3.33 | 4.5 |
| Review count (`#b7791f` on white) | 3.64 | 4.5 |
| Claude label (`#c15f3c`) | 3.87 | 4.5 |
| Local label (`#2e8b57`) | 3.89 | 4.5 |
| Gemini label (`#2f6fd6`) | 4.41 | 4.5 |
| Filter counts | 2.98 | 4.5 |
| "not set up" source chip | 2.38 | 4.5 |

Dark mode: only the filter counts (3.49) and "not set up" (3.02) fail.

### 6. Duplicate check speed — Medium

`findDuplicatePairs` compares every pair of open tasks (n²) and runs on
every page refresh: after every action and once a minute.

| Open tasks | Time | Pairs suggested |
|---|---|---|
| 200 | 64 ms | 8 |
| 500 | 338 ms | 166 |
| 1,000 | 1,496 ms | 1,512 |
| 1,666 | 3,843 ms | 5,278 |

Every other endpoint stayed under 50ms at 1,666 open tasks, with a 1.1MB
file. There's no cap on pairs shown in the duplicates box.

### 7. Malformed task — Low

A task added by hand as `{"id":"hand","title":"Typed by hand","status":"open"}`
is placed in "Drop or defer" (undefined answers count as "no").
`/api/duplicates` fails with a 500 (`notDuplicateOf` missing). Because
the page loads all its data at once, that stops the whole page loading.

### 8. Stray `- !1` — Low

An inbox file containing `- Good line`, `- !1`, `- Another good line`
puts "Another good line" in Do now: the title-less line is taken as a
header setting defaults. The comment in `src/sources/inbox.ts` says such
a line throws and leaves the file in place; it doesn't any more.

### 9. API types — Low

`POST /api/tasks {"title":"x","externalId":{"$ne":1}}` stores the object.
`POST /api/tasks/:id/reviewed-at {"reviewedAt":12345}` stores a number.
Only reachable by calling the API directly.

### 10. Sources panel structure — Low

axe: `nested-interactive` (the Sync now button is inside `<summary>`)
and `heading-order` (`h3` with no `h2` above it in the panel).

### 11. Midnight — Low

The Day view asks for the day it last showed. Left open on "Today"
overnight, it shows yesterday (correctly labelled "Yesterday"). The matrix
and Ahead do move on.

### 12. Cosmetic — Low

- Ahead with nothing in the fortnight: "Nothing on Today – Tue, 27 Oct".
- An event at 01:30–02:30 on 28 March 2027 in Europe/Dublin (01:30
  doesn't exist that night) shows as 02:30–02:30.

## What was checked and passed

**Static.** `npm test` (134 tests) in UTC, Europe/Dublin, Asia/Taipei and
America/Los_Angeles. `npm run typecheck`. ESLint over `public/app.js`
for undefined names, unused variables and use-before-define. The one
error, `DEFAULT_MINUTES` used before its declaration, is inside a
function that only runs after the module has loaded, so it can't fail.

**API.** Malformed JSON, arrays, wrong types, unknown sources and
quadrants, `__proto__`/`toString` as quadrant names, empty titles,
fractional and out-of-range slot lengths, a slot without a day, merging
a task into itself, unknown ids (404) and unknown routes (404). PATCHing
`id`, `status` or `createdAt` is ignored.

**Static file server.** `/../package.json`, `/..%2fpackage.json`,
`/%2e%2e/%2e%2e/etc/passwd`, `/public/../src/server.ts` and a null-byte
path: all 404.

**Script injection.** A task titled
`<img src=x onerror=…><script>…</script>` is shown as text in every view
and nothing runs. `javascript:` links are refused, with a message in the
edit panel.

**Data safety.** Truncated, wrong-version and BOM-prefixed files are
never overwritten. CRLF task files load. Every write goes through
temp-file-then-rename.

**Sources.** Inbox files with BOM and CRLF, empty files, header-only
files. Notes with BOM and CRLF, indented, `*` and numbered checkboxes,
`[X]` and `[x]` read as ticked, `TODO:` with emoji, 3,000-character lines
(trimmed to 200), code files ignored. Capture: duplicate `due:`, `!5`,
`#42` kept in title, last source tag wins, query strings and fragments in
links, `lunatask://` links, `at:` without `on:`.

**Dates.** A daily 09:00 Europe/Dublin event stays at 09:00 either side
of both clock changes; day counts across clock changes are exact; an
event at 01:30 on the night clocks go back is shown once.

**Browser (Chromium, 1280px and 375px).** First Do now task selected on
load. Capture with every shortcut. Pasting a block, then the same block
again ("Nothing new"). `j`/`k`, `1`–`4`, `0`, `i`, `x`, `d` and Undo for
each. Edit panel save (title, planned day, slot). Duplicate "Not the
same", merge and unmerge. Drag between quadrants. The due-date rule's
explanation when it overrules a move. Source filter. `v` cycling views.
Quadrant chips in List. Day view: `[`, `]`, `t`, timeline drawing,
removing a slot with ×, dragging to "Some time this day" and back,
double-click to edit a slotted task. Ahead: overdue section, opening a
day. Review: every card type, keyed actions, naming, Undo, summary.
Sync now from the failure banner. Server-unreachable banner, and its
clearing when the server is back. Empty states in every view. No
horizontal scrolling at 375px in any view.

## Method

Fresh servers on separate ports with throwaway task files: an empty
file, the sample data, and a generated file of 2,000 tasks (1,666 open,
1.1MB). API probes with `curl`. Browser checks with Playwright driving
Chromium, including a page on a second local origin for the cross-site
test, and axe-core 4.10.2 for accessibility. Throwaway scripts, not
part of the repo. Your real `tasks.json`, `.env` and folders weren't
touched.

**Found during the retest — Q13 (Medium), fixed.** The accessibility scan
of the review screen flagged headings from the Ahead view. The cause:
`#ahead { display: grid }` overrode the `hidden` attribute, so after you
visited Ahead its day cards stayed on screen under every other view and
the review. Fixed with a rule that `hidden` always wins; checked by
switching from Ahead to each view and to the review.

**Regression run.** 154 tests pass in UTC, Europe/Dublin, Asia/Taipei and
America/Los_Angeles; type check clean; ESLint no errors (two harmless
name-shadowing warnings). The scripted browser walkthrough (40 checks)
passes in full, including drag between quadrants and accessibility scans
of every view.
